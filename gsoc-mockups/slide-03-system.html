The Proposal
Unified Logging & Traceability System
A structured event log that captures every technical, methodological, and AI decision during a usability study — linked by a single trace ID.
Key concept · Three layers, one trace
Technical
API calls, DB writes, frame drops, network jitter
Unified Log
Every event linked by traceId, sessionId, participantId
Methodological
Task assignments, observer notes, protocol deviations
AI Decisions
Gaze detection, sentiment analysis, model confidence
Principle 01
Multi-Layer Correlation
Every event — regardless of its source layer — receives a shared trace ID, enabling researchers to ask "when the AI flagged frustration, what was happening technically and methodologically?"
Principle 02
Research-First Design
The system is built for usability researchers, not DevOps engineers. Filters, exports, and views are organized around study concepts: sessions, tasks, participants, and phases.
Principle 03
Privacy by Default
Logs are stored anonymized (P-004, not "John Doe"). An identity resolution layer enables authorized tracing without exposing PII in the log store itself.
