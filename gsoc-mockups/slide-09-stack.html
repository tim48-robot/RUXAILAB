Implementation Choice
Stack Decision: Firebase + Node.js
RUXAILAB is already built on Firebase. Firestore, Auth, Storage, and Cloud Functions are all production-ready. Introducing a separate Python server would duplicate auth and infrastructure. For a 175-hour project, that adds risk without adding value.
Existing platform already deployed on Firebase services.
Avoid maintaining dual backends and duplicated auth flows.
Fits 175-hour scope with lower delivery and integration risk.
Logging pipeline naturally fits Cloud Functions + Firestore.
Platform: Firebase. Server logic: Node.js Cloud Functions. One stack, faster delivery.
