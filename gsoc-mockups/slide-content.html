How to improve the Figma
What More Content Should Each Screen Show?
The UI already looks strong. The next step is making each module feel more believable by showing enough information for reviewers to understand the research workflow, the data model, and the value of the feature without reading a long explanation.
Keep one story thread
Reuse the same study, session, participant, and trace ID across all screens — for example Study: Mobile App Redesign, Session: S-008, Participant: P-004, Trace: T-0042. That makes the deck feel like one end-to-end flow instead of five isolated pages.

Overview

Summary first
Ingestion health: events/min, dropped logs, delayed sync, unresolved traces.
Research KPIs: active sessions, protocol deviations, AI confidence, anomaly count.
Investigation queue: top anomalies and "needs review" sessions.

Log Explorer

Search & inspect
Concrete filters: actor, event type, severity, task, time range, trace ID.
Better columns: timestamp, source, action, target, trace, correlation status.
Payload drawer: normalized fields plus raw JSON preview for one selected event.

Trace View

Cause → effect
Parent/child chain: linked events from task start to exportable evidence.
Timing detail: latency per step, missing span warnings, out-of-order events.
Jump actions: open raw log, open session, export this trace only.

Lifecycle

Coverage by phase
Phase checkpoints: setup, consent, execution, debrief, export readiness.
Coverage gaps: "recording started before consent" or "no observer note in Task 3".
Protocol context: hints given, pause events, deviations, recovery notes.

Export

Reproducible output
Scope selection: whole study, one session, one participant, one trace.
Privacy controls: anonymization preset, PII redaction, AI output inclusion.
Metadata: schema version, row count, exported by, timestamp, reproducibility note.

Cross-screen details

Small but important
Show system states: loading, empty, delayed ingest, permission denied, partial trace.
Add researcher value: one short sentence saying why this module helps analysis.
Keep consistency: same IDs, same color semantics, same anomaly labels across tabs.
Best improvement direction
If you only change one thing, make each screen tell a clearer research story: what happened, where it happened, why it matters, and what the researcher can do next. That is usually what maintainers mean when they ask a design to “show all the information”.
